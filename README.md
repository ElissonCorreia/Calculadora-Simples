# Calculadora Simples em Java

Uma aplicação de calculadora no terminal desenvolvida em Java, capaz de realizar operações matemáticas fundamentais. Este projeto foi desenvolvido com foco em praticidade, lógica de programação e boas práticas de código.

---

Funcionalidades

- **Soma** (`+`)
- **Subtração** (`-`)
- **Multiplicação** (`*`)
- **Divisão** (`/`) — *com tratamento contra divisão por zero*
- **Sair** do programa a qualquer momento

Tecnologias Utilizadas

- **Linguagem:** Java (JDK 8 ou superior)
- **Entrada de dados:** `java.util.Scanner`
